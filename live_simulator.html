Inerter live simulator

Three race-car corners drive over the same road at the same time: a conventional suspension, a J-damper with an ideal inerter, and a J-damper with the CFD-measured fluid inerter. The physics (a quarter-car model) runs live in your browser, with suspension settings optimised in the project. Movements are magnified so you can see them.

Grip score = RMS of the tyre-load fluctuation as a % of static load, averaged since the last reset (lower is better). On the race track it settles near the project result: about 8.6 % less fluctuation with the ideal inerter and about 4 % with the CFD inerter.

Model: quarter car ms = 250 kg, mu = 35 kg, ks = 80 kN/m, kt = 300 kN/m, road ISO 8608 (class A track / class C rough). J-damper branch: spring k2, damper c2 and inerter b in series, in parallel with the main spring. Values come from the project optimisation (python/run_cfd_vehicle_study.py). CFD inerter: nominal b = 107.7 kg, effective inertance 1.06 × b and parasitic damping 64 N·s/m per kg (CFD values at 10 Hz). With the full frequency-dependent CFD model the gain is 5.0 %; this fixed-frequency version gives about 4 %.
